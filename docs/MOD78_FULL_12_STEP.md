# SHADOW MOD-78 — Full 12-Step Master Execution

MOD-78 composes the validated TwelveCoreRuntime and the Super Nice 150-Core registry into one explicit twelve-stage master pipeline.

1. Understand — normalize intent and call the reasoning core.
2. Model route — expose configured providers; network model calls stay in the cloud agent.
3. Voice / multimodal — connect Android speech/camera transport to provider adapters.
4. Memory — invoke governed semantic memory.
5. Web discovery — use web search when freshness is requested.
6. GitHub / development — use governed development adapters.
7. Phone / devices — keep Accessibility phone control plus optional companion/device adapters.
8. Agent loop — understand, plan, route, execute, observe, verify, continue.
9. Security / approval — stop risky actions before side effects without confirmation.
10. Execute — run the classified core.
11. Verify — verify the execution result.
12. Deliver — return a trace-bound delivery envelope.

No external success is fabricated. Missing provider/device adapters are explicit. There is no Shadow subscription gate or internal credit meter. Provider credentials are never embedded in the APK.

Python surface: run_master_pipeline(...) in shadow/android_runtime.py
Android surface: ShadowPythonRuntimeBridge.superniceRun(...)
Cloud surface: POST /v1/master/run
