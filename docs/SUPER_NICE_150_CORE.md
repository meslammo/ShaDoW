## Free-first rule
The Shadow application itself has no credit/points/subscription meter. Self-hostable open-model providers can be used without a commercial API bill where the operator has the required compute/network. Commercial providers remain optional and subject to their own terms and pricing.

## Evolution rule
A self-evolution change must be represented as a proposal, staged in an isolated environment, tested, benchmarked, and made rollback-capable. Permanent activation requires explicit Master approval.

## External adapter rule
An adapter is considered live only after credentials/device access are configured through secure runtime configuration and a real integration test succeeds.
